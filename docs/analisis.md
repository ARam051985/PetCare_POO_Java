# Tabla de análisis
La tabla de análisis sirve para identificar las clases, el tipo de clase, atributos de cada clase y métodos de cada clase antes de modelar y codificar el problema.

| N° | Clase candidata   | Tipo (concreta, abstracta o interfaz) | Atributos principales                             | Responsabilidades (métodos)                                           | Justificación                                                |
|----|-------------------|---------------------------------------|---------------------------------------------------|-----------------------------------------------------------------------|--------------------------------------------------------------|
| 1  | Persona           | Abstracta                             | nombre <br/> apellido <br/> telefono <br/> correo | getNombre() <br/> getApellido() <br/> getTelefono() <br/> getCorreo() | "Persona" engloba varios puestos de trabajo de cada persona. |
| 2  | Dueño             | Concreta                              | dirección                                         | getDireccion()                                                        | "Dueño" hereda de "Persona"                                  |
| 3  | Veterinario       | Concreta                              | cedulaProfesional <br/> especialidad              | getCedulaProfesional() <br/> getEespecialidad()                       | "Veterinario" hereda de "Persona"                            |
| 4  | Recepcionista     | Concreta                              | turno                                             | getTurno()                                                            | "Recepcionista" hereda de "Persona"                          |
| 5  | Mascota           | Abstracta                             | nombre <br/> edad <br/> peso <br/> dueño          | getNombre() <br/> getEdad() <br/> getPeso() <br/> getDueño()          | "Mascota" engloba a varios animales                          |
| 6  | Perro             | Concreta                              | raza <br/> nivelEnergia <br/> sonido              | getRaza() <br/> getlEnergia() <br/> emitirSonido()                    | "Perro" hereda de "Mascota"                                  |
| 7  | Gato              | Concreta                              | esDomestico <br/> sonido                          | esDomestico() <br/> emitirSonido()                                    | "Gato" hereda de "Mascota"                                   |
| 8  | Ave exótica       | Concreta                              | longitudAlas <br/> sonido                         | getLongitudAlas() <br/> emitirSonido()                                | "Ave exótica" hereda de "Mascota"                            |
| 9  | Historial Clínico | Concreta                              | consultas                                         | agregarConsulta() <br/> getHistorialDeConsultas()                     | Cada mascota tiene su historial clínico                      |
| 10 | Cita              | Concreta                              | estadoCita <br/> fechaHoraCita                    | getEstadoCita() <br/> getFechaHoraCita()                              | Una cita relaciona a una mascota con un veterinario          |
| 11 | EstadoCita        | Enumeración                           | PROGRAMADA <br/> ATENDIDA <br/> CANCELADA         | -                                                                     | Estado de las citas                                          |
| 12 | Servicio          | Interfaz                              | -                                                 | calcularCosto()                                                       | Cada servicio de la clínica calculará el costo               |
| 13 | Consulta general  | Concreta                              | tarifaBase                                        | getTarifaBase() <br/> calcularCosto()                                 | "Consulta general" hereda de "Servicio"                      |
| 14 | Vacunación        | Concreta                              | costoVacuna                                       | getCostoVacuna() <br/> calcularCosto()                                | "Vacuna" hereda de "Servicio"                                |
| 15 | Cirugía           | Concreta                              | complejidad <br/> horasQuirofano                  | getComplejidad() <br/> getHorasQuirofano() <br/> calcularCosto()      | "Cirugía" hereda de "Servicio"                               |

# Clases descartadas
Descarté la clase candidata "Consultorio" ya que no indican procedimientos ni información relevante a modelar, y descarté la clase candidata "Comprobante" ya que un comprobante nace de la toma de otros datos de otras tablas (o de otras clases).
