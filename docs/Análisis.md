# Tabla de análisis
La tabla de análisis sirve para identificar las clases, el tipo de clase, atributos de cada clase y métodos de cada clase antes de modelar y codificar el problema.

| N° | Clase candidata   | Tipo (concreta, abstracta o interfaz) | Atributos principales                                                                       | Responsabilidades (métodos)                                                                                                                                                                                                                               | Justificación                                                                                                             |
|----|-------------------|---------------------------------------|---------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------|
| 1  | Persona           | Abstracta                             | nombre <br/> apellido <br/> telefono <br/> correo                                           | getDatosPersonales() <br/> setNombre() <br/> setApellido() <br/> setTelefono() <br/> setCorreo()                                                                                                                                                          | "Persona" engloba varios puestos de trabajo de cada persona.                                                              |
| 2  | Dueño             | Concreta                              | dirección                                                                                   | getDireccion() <br/> setDireccion()                                                                                                                                                                                                                       | "Dueño" hereda de "Persona". Tiene dirección y mascotas. Son los clientes de la clínica.                                  |
| 3  | Veterinario       | Concreta                              | cedulaProfesional <br/> especialidad                                                        | getCedulaProfesional() <br/> getEespecialidad() <br/> setCedulaProfesional() <br/> setEspecialidad()                                                                                                                                                      | "Veterinario" hereda de "Persona". Tiene cédula profesional y especialidad. Son las personas que atienden las citas.      |
| 4  | Recepcionista     | Concreta                              | turno                                                                                       | getTurno() <br/> setTurno()                                                                                                                                                                                                                               | "Recepcionista" hereda de "Persona". Tiene turno. Son las personas que registran y modifican citas.                       |
| 5  | Mascota           | Abstracta                             | nombre <br/> edad <br/> peso <br/> dueño                                                    | getDatosMascota() <br/> setNombre() <br/> setEdad() <br/> setPeso() <br/> setDueño() <br/> emitirSonido()                                                                                                                                                 | "Mascota" engloba a varios animales. Cada mascota emite un sonido.                                                        |
| 6  | Perro             | Concreta                              | raza <br/> nivelEnergia <br/>                                                               | getRaza() <br/> getNivelEnergia() <br/> setRaza() <br/> setNivelEnergia() <br/> emitirSonido()                                                                                                                                                            | "Perro" hereda de "Mascota". Tiene raza y nivel de energía.                                                               |
| 7  | Gato              | Concreta                              | esDomestico <br/>                                                                           | esDomestico() <br/> setEsDomestico() <br/> emitirSonido()                                                                                                                                                                                                 | "Gato" hereda de "Mascota". Se define si es doméstico o no.                                                               |
| 8  | Ave exótica       | Concreta                              | longitudAlas <br/>                                                                          | getLongitudAlas() <br/> setLongitudAlas() <br/> emitirSonido()                                                                                                                                                                                            | "Ave exótica" hereda de "Mascota". | 9  | Historial Clínico | Concreta                              | consultas                                                                                   | añadirConsulta() <br/> mostrarHistorialConsultas()                                                                                                                                                                                                        | Cada mascota tiene su historial clínico, el cual es una lista de consultas.                                               |
| 10 | Consulta          | Concreta                              | fechaHora <br/> diagnostico <br/> tipoTratamiento                                           | mostrarConsulta()                                                                                                                                                                                                                                         | En el historial clínico se guardan estas consultas.                                                                       |
| 11 | Consultorio       | Concreta                              | numero                                                                                      | getNumero() <br/> setNumero()                                                                                                                                                                                                                             | En cada consultorio se atiende las citas de los dueños (clientes).                                                        |
| 12 | Cita              | Concreta                              | mascota <br/> veterinario <br/> consultorio <br/> servicio <br/> fechaHora <br/> estadoCita | getMascota() <br/> getVeterinario() <br/> getConsultorio() <br/> getServicio() <br/> getFechaHora() <br/> getEstadoCita() <br/> setMascota() <br/> setVeterinario() <br/> setConsultorio() <br/> setServicio() <br/> setFechaHora() <br/> setEstadoCita() | Una cita relaciona a una mascota con un veterinario.                                                                      |
| 13 | EstadoCita        | Enumeración                           | PROGRAMADA <br/> ATENDIDA <br/> CANCELADA                                                   | -                                                                                                                                                                                                                                                         | Estado de las citas.                                                                                                      |
| 14 | Servicio          | Interfaz                              | -                                                                                           | calcularCosto()                                                                                                                                                                                                                                           | Cada servicio de la clínica calculará el costo.                                                                           |
| 15 | Consulta general  | Abstracta                             | tarifaBase                                                                                  | setTarifaBase() <br/> calcularCosto()                                                                                                                                                                                                                     | "Consulta general" implementa "Servicio". | 16 | Consulta estándar | Concreta                              | -                                                                                           | -                                                                                                                                                                                                                                                         | "Consulta estándar" hereda de "Consulta general". | 17 | Vacunación        | Concreta                              | costoVacuna                                                                                 | setTarifaBase() <br/> setCostoVacuna() <br/> calcularCosto()                                                                                                                                                                                              | "Vacuna" implementa "Servicio". Tiene tarifa por hora, nivel de complejidad y cantidad de horas del quirófano a ocupar.  |

# Clases descartadas
Descarté la clase candidata "Clínica", ya que no indican procedimientos ni información relevante a modelar, y descarté la clase candidata "Comprobante", ya que un comprobante nace de la toma de otros datos de otras tablas (o de otras clases).
