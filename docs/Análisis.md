# Tabla de análisis
La tabla de análisis sirve para identificar las clases, el tipo de clase, atributos de cada clase y métodos de cada clase antes de modelar y codificar el problema.

| N° | Clase candidata   | Tipo (concreta, abstracta o interfaz) | Atributos principales                                | Responsabilidades (métodos)                                                                          | Justificación                                                                                                             |
|----|-------------------|---------------------------------------|------------------------------------------------------|------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------|
| 1  | Persona           | Abstracta                             | nombre <br/> apellido <br/> telefono <br/> correo    | getDatosPersonales() <br/> setDatosPersonales()                                                      | "Persona" engloba varios puestos de trabajo de cada persona.                                                              |
| 2  | Dueño             | Concreta                              | dirección                                            | getDireccion() <br/> setDireccion()                                                                  | "Dueño" hereda de "Persona". Tiene dirección y mascotas. Son los clientes de la clínica.                                  |
| 3  | Veterinario       | Concreta                              | cedulaProfesional <br/> especialidad                 | getCedulaProfesional() <br/> getEespecialidad() <br/> setCedulaProfesional() <br/> setEspecialidad() | "Veterinario" hereda de "Persona". Tiene cédula profesional y especialidad. Son las personas que atienden las citas.      |
| 4  | Recepcionista     | Concreta                              | turno                                                | getTurno() <br/> setTurno()                                                                          | "Recepcionista" hereda de "Persona". Tiene turno. Son las personas que registran y modifican citas.                       |
| 5  | Mascota           | Abstracta                             | nombre <br/> edad <br/> peso <br/> dueño             | getDatosMascota() <br/> setDatosMascota()                                                            | "Mascota" engloba a varios animales. Cada mascota emite un sonido.                                                        |
| 6  | Perro             | Concreta                              | raza <br/> nivelEnergia <br/>                        | getRaza() <br/> getNivelEnergia() <br/> setRaza() <br/> setNivelEnergia() <br/> emitirSonido()       | "Perro" hereda de "Mascota". Tiene raza y nivel de energía.                                                               |
| 7  | Gato              | Concreta                              | esDomestico <br/>                                    | esDomestico() <br/> setEsDomestico() <br/> emitirSonido()                                            | "Gato" hereda de "Mascota". Se define si es doméstico o no.                                                               |
| 8  | Ave exótica       | Concreta                              | longitudAlas <br/>                                   | getLongitudAlas() <br/> setLongitudAlas() <br/> emitirSonido()                                       | "Ave exótica" hereda de "Mascota". Tiene longitud de alas.                                                                |
| 9  | Emitir sonido     | Abstracta                             | -                                                    | emitirSonido()                                                                                       | Cada animal (o mascota) emite un sonido distinto.                                                                         |
| 10 | Historial Clínico | Concreta                              | consultas                                            | añadirConsulta() <br/> mostrarHistorialConsultas()                                                   | Cada mascota tiene su historial clínico, el cual es una lista de consultas.                                               |
| 11 | Consulta          | Concreta                              | fechaHora <br/> diagnostico <br/> tipoTratamiento    | mostrarConsulta()                                                                                    | En el historial clínico se guardan estas consultas.                                                                       |
| 12 | Consultorio       | Concreta                              | numero                                               | getNumero() <br/> setNumero()                                                                        | En cada consultorio se atiende las citas de los dueños (clientes).                                                        |
| 13 | Cita              | Concreta                              | fechaHora <br/> estadoCita                           | getFechaHora() <br/> getEstadoCita() <br/> programarCita() <br/> atenderCita() <br/> cancelarCita()  | Una cita relaciona a una mascota con un veterinario.                                                                      |
| 14 | EstadoCita        | Enumeración                           | PROGRAMADA <br/> ATENDIDA <br/> CANCELADA            | -                                                                                                    | Estado de las citas.                                                                                                      |
| 15 | Servicio          | Interfaz                              | -                                                    | calcularCosto()                                                                                      | Cada servicio de la clínica calculará el costo.                                                                           |
| 16 | Consulta general  | Abstracta                             | tarifaBase                                           | setTarifaBase() <br/> calcularCosto()                                                                | "Consulta general" implementa "Servicio". Tiene tarifa base.                                                              |
| 17 | Vacunación        | Concreta                              | costoVacuna                                          | setCostoVacuna() <br/> calcularCosto()                                                               | "Vacuna" implementa "Servicio". Hereda de "Consulta general" para obtener la tarifa base y se suma el costo de la vacuna. |
| 18 | Cirugía           | Concreta                              | tafiraPorHora <br/> complejidad <br/> horasQuirofano | setTarifaPorHora() <br/> setNivelComplejidad() <br/> setHorasQuirofano() <br/> calcularCosto()       | "Cirugía" implementa "Servicio". Tiene tarifa por hora, nivel de complejidad y cantidad de horas del quirófano a ocupar.  |

# Clases descartadas
Descarté la clase candidata "Clínica", ya que no indican procedimientos ni información relevante a modelar, y descarté la clase candidata "Comprobante", ya que un comprobante nace de la toma de otros datos de otras tablas (o de otras clases).
