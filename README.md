# Examen parcial integrador
## Caso de estudio: clínica veterinaria "PetCare"
La clínica veterinaria PetCare necesita un sistema de consola para
registrar a sus mascotas y dueños, agendar citas, registrar consultas
y calcular lo que cobra por cada servicio.

## Tecnologías utilizadas
- Versión de Java utilizada: 2026.2.1 
- Herramienta UML utilizada: draw.io
- IDE utilizado: IntelliJ IDEA

## Método de la solución
Acá irá el diagrama de clases (en imagen) y una explicación breve de
las decisiones de diseño: qué es herencia, qué es interfaz y por qué
elegí agregación o composición en cada caso.

## Estructura del proyecto 
Acá irá el Árbol de carpetas y paquetes, con una línea que explicará
el propósito de cada paquete.

## Conceptos aplicados
Acá irá una tabla que indique en qué archivo y línea se aplica cada
tema: herencia, clase abstracta, interfaz, polimorfismo, sobrecarga,
composición, etcétera.

## Instalación y ejecución
Acá irán los pasos exactos para clonar, compilar y ejecutar desde
la consola. Alguien que no conoce mi proyecto debe poder hacerlo
sin ayuda.

## Ejemplo de uso
Acá irán las capturas o bloques de texto con el escenario de
demostración y su salida.

## Reglas de negocio
Acá se explicará cómo y dónde se validan en el código.

## Reflexión
Acá detallaré qué aprendí, qué fue lo más difícil, qué mejoraría 
y cómo usé la IA.
